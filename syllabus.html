Project learning topics

HTML and CSS topics used

This page shows how the project connects to Units I, II and III.

UNIT I

HTML Fundamentals

  • HTML document structure
  • Elements and attributes
  • Text formatting and lists
  • Hyperlinks between pages
  • Basic SEO title and headings
UNIT II

Semantic HTML and Forms

  • Header, nav, main, section and footer
  • Forms and form controls
  • Input types and validation
  • Accessible labels
  • Responsive content structure
UNIT III

Cascading Style Sheets

  • CSS selectors and colors
  • Typography and box model
  • Flexbox and grid layout
  • Hover effects and transitions
  • Responsive web design
The project intentionally keeps the code at a basic college-project level and focuses on the listed syllabus topics.
