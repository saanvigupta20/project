About ResourceLoop

Student Academic Resource Exchange System

♻️

The problem we want to solve

Students often need textbooks and academic equipment for their courses. At the same time, other students may have items they no longer use. ResourceLoop presents a simple way to connect these students.

Our objective

To make academic resources easier to find, reuse and exchange at student-friendly prices.

Project features

  • Multiple linked HTML pages
  • Search and category filters
  • HTML forms and basic validation
  • Tables, navigation links and responsive CSS layout
  • HTML and CSS for page layout and listing cards
