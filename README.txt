RESOURCELOOP - STUDENT ACADEMIC RESOURCE EXCHANGE SYSTEM

HOW TO RUN
1. Extract ResourceLoop_HTML_CSS.zip to a folder.
2. Open the extracted folder.
3. Double-click index.html to open the website in your browser.
4. Use the navigation links to open the different pages.

FILES
index.html        Home page
browse.html       Sample listings with category jump links and contact details
post.html         HTML form with built-in browser validation
how-it-works.html Steps for using the website
about.html        Project information
contact.html      HTML contact form demonstration
syllabus.html     How the project relates to Units I, II and III
style.css         Styling, responsive layout and CSS effects

SYLLABUS
The project uses HTML fundamentals, hyperlinks, semantic page structure, forms,
input types, required-field validation, CSS selectors, colors, typography,
box model, Flexbox/Grid, hover effects and responsive design.

IMPORTANT LIMITATION
JavaScript has been removed. Therefore, HTML/CSS alone cannot dynamically search
and filter listings, save newly submitted items, or send contact messages.
The browse page uses static sample listings and category links; forms use the
browser's built-in validation but do not save data. All existing page files and
navigation links are retained. No backend is used.
